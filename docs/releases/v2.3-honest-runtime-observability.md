# v2.3 Honest Runtime Observability

Released: 2026-06-01

Current name note: this release was originally cut under the Vipin Council / `vipin-council` name. The current repository identity is `WEIPING_COUNCIL`, with Weiping Council as the human-readable product name.

## Why This Release Exists

Vipin Council previously behaved like a powerful demo: it could deliberate, but it also hid provider assumptions, contained unsafe credential patterns, depended on retired local coordination paths, and had no automated backend test suite. v2.3 turns the project into a more honest open-source foundation.

## What Changed

- Added `backend/runtime.py` for environment-only provider configuration, readiness checks, and redacted public provider status.
- Removed hard-coded provider credentials from the router.
- Split council member IDs from provider model IDs so protocol maps do not collapse multiple members into one `gpt-5.5` key.
- Added explicit degraded behavior when provider configuration is missing.
- Added session-scoped model call traces with role, model, redacted provider status, latency, attempts, and error kind.
- Rebuilt the orchestrator into a single implementation with context, routing, decomposition, protocol, refinement, and total timing metrics.
- Added response fields: `metrics`, `provider_health`, `model_call_traces`, `degraded`, and `warnings`.
- Upgraded `/api/health` to report provider readiness, agentmemory readiness, version, warnings, and degraded state without exposing raw provider or memory URLs.
- Replaced retired local coordination reads with an `agentmemory` REST context loader. Unavailable context recall now marks the run degraded.
- Updated the CLI status surface to show degraded state, provider readiness, and agentmemory state.
- Made CLI status output ASCII-friendly on Windows and trimmed raw localized connection errors.
- Added a React runtime evidence panel for provider readiness, timing, warnings, and degraded state.
- Fixed the React backend banner so degraded runtime state is not mislabeled as backend downtime.
- Added local-first CORS configuration through `VC_CORS_ORIGINS`; wildcard CORS is not the default.
- Implemented real `standard_path` routing so SmartRouter's standard tier no longer falls through into the full requested protocol.
- `/api/query` now rejects unknown protocols with HTTP 400 and returns the actual executed result protocol, including `fast_path` or `standard_path`.
- Parallelized independent provider calls in consensus, red team, specialist verification, and tournament initial answer collection.
- Added a project Codex skill, now located at `.codex/skills/weiping-council/SKILL.md`, for reproduction, maintenance, monitoring, release, and continuous upgrade work.
- Added `LICENSE` and GitHub Actions CI for backend tests, lint, frontend build, and source safety scanning.
- Added backend tests for runtime configuration, observability, concurrent trace scoping, provider failure handling, agentmemory context, and CLI health formatting.

## Operator Contract

- Secrets live only in environment variables or ignored local `.env` files.
- Missing credentials are a first-class degraded state.
- agentmemory is optional at runtime, but unavailable memory is reported as a warning and marks the affected run degraded.
- Public health and trace payloads expose readiness, source labels, missing field names, attempts, latency, and error classes. They do not expose API keys or raw provider URLs.
- Session JSON is intentionally inspectable and can be used as a lightweight audit artifact.
- `deepseek-cli` may help test DeepSeek credentials, and `WEIPING_LAB` may consume session JSON, but Weiping Council remains a standalone provider-agnostic runtime.

## Design References

This release inspected current source code from:

- Open WebUI `backend/open_webui/main.py` for separate health and readiness checks.
- LiteLLM `litellm/router.py` for model/deployment identity separation, indexes, health filtering, and cooldown handling.
- CrewAI `src/crewai/project/crew_base.py` for config-driven agent/task loading.

Weiping Council adopts the relevant ideas without vendoring those projects: redacted readiness, identity separation, and reproducible configuration.
